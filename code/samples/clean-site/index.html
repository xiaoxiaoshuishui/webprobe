为什么这个站点是"干净"的

检查项本站在做的事
JS 异常所有可能失败的分支都有 try/catch 或 .catch()
未处理拒绝fetch 链路末尾一定有 .catch()
控制台输出完全不调用 console.error / console.warn
HTTP 状态站点内所有请求都指向真实存在的静态文件，全部 200
资源加载CSS / JS / 图标 / 状态 JSON 全部随目录一起发布
主线程只有有界的 rAF 动画（200ms）与短定时器，无阻塞循环
