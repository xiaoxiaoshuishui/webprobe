常见问题

下面是集成方最常问的 6 个问题。找不到答案可以联系我们。

1. 站点需要联网吗？

不需要。所有资源（CSS、JS、图标、状态 JSON）都随目录一起发布，不引用任何外部域名。

2. 为什么状态数据是从 /api/status.json 读的？

它就是站点自带的静态文件，真实路径为 api/status.json， 由静态服务器直接返回 HTTP 200，不依赖任何服务端重写规则，从不返回 4xx/5xx。 另有一份内容相同的 data/status.json 便于对照，你也可以直接打开 /data/status.json 查看原文。

3. 表单提交会真的发请求吗？

不会。本站是纯前端演示：校验通过后在页面上给出成功提示，不发起任何网络请求。

4. 页面会有卡顿吗？

不会。唯一的动画是 requestAnimationFrame 驱动的 200ms 有界进度条， 没有 while 阻塞循环，也没有长同步任务。

5. 出现报错怎么办？

先看浏览器控制台与网络面板：本站正常情况下既没有 error 级日志， 也没有失败请求。若确实异常，请通过联系表单反馈。

6. 支持多语言吗？

配置项 locales 支持多语言，默认启用 zh-CN。详见配置项。
