5 分钟快速开始

按顺序完成下面 4 步，就能把 Clean Docs 跑起来。

  1. 1. 准备目录

    把文档目录放在站点根目录下，保持相对路径引用。

  2. 2. 写配置

    在根目录创建配置文件，填写 name 与 version。

  3. 3. 校验

    运行校验，确认没有未解析的引用与失效链接。

  4. 4. 发布

    产物是纯静态文件，任何静态服务器都能托管。

示例：校验并发布

下面的命令只是文档文本，页面不会执行它们。

# 1. 校验文档引用
cleandocs check --strict

# 2. 生成静态站点
cleandocs build --out ./dist

# 3. 本地预览（任意静态服务器均可）
npx serve ./dist
